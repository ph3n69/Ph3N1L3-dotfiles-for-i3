# Ph3N1L3-dotfiles-for-i3
ever wanted to experience the luxurius eyecandy of hyprland you saw on all of these repetitive hyprslop r/unixporn posts but dont want to spent atleast a decade changing hyprland config files and want the eyecandy with the performance without wayland? then freely grab this Ph3N1L3 configuration files and paste them right away with instructions!

What do i need to have preinstalled?
You atleast need polybar,kitty (the terminal),rofi,i3,picom v13 and x11
Opcional installs:
neofetch,fastfetch,dripfetch,cava,btop

how do i apply them?
you need to use your file manager (thunar,dolphin etc) and just replace your existing configuration file with the configs given inside the folders in the repository and here is the default usual directories you would find:

/home/user/.config/i3/ --- i3 config directory
rofi --- no configuration needed for rofi just use the built in theme changer and apply your selected theme :3 
/home/user/.config/btop/ --- btop config
/home/user/.config/polybar/ ---polybar config files (if they dont exist then create the directory)
/home/user/.config/kitty/kitty.conf --- kitty configuration file
/home/user/.config/picom.conf --- picom configuration file
/home/user/.config/fastfetch/config.jsonc --- fastfetch config file
/home/user/.config/dripfetch/ --- dripfetch config file (no need to change i just mencioned for ne reason idk)
/home/user/.config/cava/ --- cava config file
/home/ph3n/.config/tmux/ ---tmux config file if you want a tiling wm inside the terminal in a tiling wm lol
/home/user/.config/unifetch/config.conf ---neofetch config file
